# Security

If you find a security issue, please don't open a public issue. Report it privately from the **Security** tab of this
repository, using **Report a vulnerability**.

Tell me what you found and how to reproduce it. Only the latest version on `main` gets fixes for now.

How Ludra protects session tokens and release signing, and the rules contributors follow to keep it that way, is in
[`docs/security.md`](docs/security.md). The release process and the GitHub settings it relies on are in
[`docs/releasing.md`](docs/releasing.md).
